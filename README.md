# CodeAlpha_Data-Visualization-
# 🎵 Spotify Songs Dataset – Data Visualization Project

This project is part of **CodeAlpha Data Analytics Internship (Task 3: Data Visualization)**.  
The goal is to analyze the Spotify Songs Dataset using visual analytics to uncover trends in musical features, popularity, and artist representation.

---

## 📂 Dataset  
**Ultimate Spotify Tracks Dataset (Kaggle)**  
🔗 https://www.kaggle.com/datasets/zaheenhamidani/ultimate-spotify-tracks-db

The dataset contains 16,000+ tracks with attributes such as:
- Popularity  
- Artists  
- Danceability  
- Energy  
- Loudness  
- Valence  
- Tempo  
- Duration  
- Release Year  

---

## 🎯 Objectives
- Visualize core audio features  
- Identify patterns in song popularity  
- Compare relationships between musical attributes  
- Analyze artist frequency and yearly track trends  
- Create insightful visual charts for interpretation  

---

## 📊 Visualizations Created
- Top 10 Artists Bar Chart  
- Song Popularity Histogram  
- Danceability Distribution Plot  
- Energy vs Loudness Scatter Plot  
- Danceability vs Popularity  
- Tempo vs Popularity  
- Year-wise Track Release Count Plot  
- Correlation Heatmap of Audio Features  

---

## 🔑 Key Insights
- High-energy songs tend to have higher loudness levels  
- Danceability has a mild positive correlation with popularity  
- Tempo does not strongly affect popularity  
- Most songs fall within the popularity range of 40–60  
- Track releases have increased significantly over the years
